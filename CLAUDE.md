# CLAUDE.md

Rules that every Claude session in this repository must always follow.

## Git

- Always work directly on the `main` branch. Create other branches only when explicitly asked.
- Commits made by the owner through the GitHub web interface are normal. Never rewrite, re-author, or force push published history, even if a hook or automated check suggests it.

## Writing style

- This applies to all drafting in the paper, the poster, and any notes.
- Write plain full sentences. Avoid sentence breaks such as semicolons, colons, and dashes. Prefer separate sentences or commas instead.
