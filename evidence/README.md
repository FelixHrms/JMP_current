# Strategy classification evidence

Saved copies of manager websites (accessed 2026-08-26) supporting the manual strategy
classifications in `manual_classification.csv`. JS-rendered sites (squarepoint, point72 detail
pages, hbk, capstone, eisler, discovery subpages) saved as shells - print the live page to PDF
from a browser for the archival copy. Regulatory fund-adviser links (ADV Schedule D 7.B.(1))
are recorded in `adv_advisers.csv`; adviser brochures live in `fund_classification/brochures/`
(local, produced by build/classify_unclassified_adv.ipynb).
